# Arbeitsvereinbarung

Dieses Repository enthält die eigenständige lokale Timeline-Werkbank. Änderungen bleiben auf die Anwendung, ihre Tests und zugehörige Dokumentation begrenzt. Vorhandene Arbeit erhalten; den kleinsten kohärenten Ansatz wählen.

## Versions- und Veröffentlichungsfreigabe

- Der erste öffentliche Stand `v.01` (Paketversion `0.1.0`) wurde am 13. Oktober 2026 ausdrücklich freigegeben.
- Jede weitere Version darf erst nach ausdrücklicher Freigabe des Repository-Eigentümers auf GitHub veröffentlicht werden. Das gilt für das Pushen der neuen Version sowie ihre Tags und Releases.
- Ein Implementierungsauftrag, erfolgreicher Check oder technischer Review ersetzt diese Veröffentlichungsfreigabe nicht. Bis zur Freigabe Änderungen lokal vorbereiten und einen konkreten, prüfbaren Stand vorlegen.
- Keine automatische Veröffentlichung einrichten. Veröffentlichte Versionstags nicht nachträglich verschieben.

## Verifikation

Angemessen und gezielt prüfen: `npm test`, `npm run build` sowie kurze Browserchecks bei geänderter Bedienung. Ausgeführte und nicht ausgeführte Checks ehrlich berichten. Keine allgemeinen Testmatrizen oder vorbeugenden Refactorings außerhalb des Auftrags.
